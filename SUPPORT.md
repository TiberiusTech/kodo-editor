# Kodo support

## Public support

Use GitHub Issues when a report can be discussed publicly:

- [Bug report](https://github.com/TiberiusTech/kodo-editor/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/TiberiusTech/kodo-editor/issues/new?template=feature_request.yml)

Before opening an issue, search existing reports and install the latest App Store version when possible.

## Private support

Email [info@ttstudio.net](mailto:info@ttstudio.net) when the request contains account-specific, server-specific or otherwise private details.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Helpful details

Include:

- Kodo version
- iPhone or iPad model
- iOS or iPadOS version
- the workflow being used, such as editor, local AI, SSH, SFTP, GitHub or SQLite
- exact reproduction steps
- expected and actual result
- a redacted screenshot or log, if useful

Do not include passwords, private keys, access tokens, server addresses, personal information, confidential source code or unredacted logs.

App Store reviews are valuable feedback, but GitHub Issues or email are better places for troubleshooting because they allow follow-up questions.
