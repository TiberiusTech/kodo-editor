# Kodo roadmap

This roadmap describes product directions, not delivery promises. Priorities may change after user feedback, platform changes and technical evaluation.

## Current priorities

- improve editor stability and performance on large files
- make local-model setup and memory expectations clearer
- refine autocomplete quality and AI diff review
- strengthen SSH, SFTP and remote-project workflows
- expand documentation, accessibility and localization quality

## Under consideration

- richer workspace and project navigation
- more configurable local-AI behavior
- improved Git workflows
- additional database and structured-data tools
- more transparent diagnostics for remote connections and model loading

## How to influence priorities

Open a focused [feature request](https://github.com/TiberiusTech/kodo-editor/issues/new?template=feature_request.yml) that explains:

1. the workflow you are trying to complete
2. what currently blocks or slows you down
3. why the change is useful on iPhone or iPad
4. any privacy, performance or compatibility constraints

Requests are evaluated by user value, technical feasibility, privacy impact and maintenance cost—not only by reaction count.
