# Contributing

Thank you for helping improve Kodo's public documentation and support resources.

## What belongs here

- documentation corrections
- clearer setup or troubleshooting guidance
- reproducible bug reports
- focused feature requests based on a real workflow
- accessibility and localization feedback

The Kodo application source code is not part of this repository, so application-code pull requests cannot be accepted here.

## Documentation pull requests

1. Keep each pull request focused on one topic.
2. Explain the user problem the change solves.
3. Use concise, platform-neutral language unless a device-specific detail matters.
4. Do not add secrets, private source code, personal data or copied proprietary documentation.
5. Check all edited links and Markdown before submitting.

Submitting a contribution does not guarantee inclusion. Product behavior and App Store information remain authoritative over community documentation.
