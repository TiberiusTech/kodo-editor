## Product summary

Kodo Editor is a private, offline AI code editor and mobile IDE for iPhone and iPad. It combines on-device Qwen models through `llama.cpp`, an interactive SSH terminal, SFTP and FTP remote files, GitHub workflows, SQLite and PostgreSQL tools, CSV editing and local web preview.

Kodo is currently free, requires no Kodo account or subscription, and is designed so AI prompts and source code can be processed on the device.
